# 面试演示脚本（10 分钟版）

## 准备（提前 5 分钟）

1. 运行 `scripts/start_web.bat`（Windows）或 `sh scripts/start_web.sh`（macOS/Linux），自动启动后端 + 前端 + IM 长连接
2. 打开钉钉，准备好「小苏」的**私聊**窗口
3. 确认浏览器自动打开 http://localhost:5173

## 演示流程（按顺序）

| # | 环节 | 操作 | 讲解要点 |
|---|---|---|---|
| 1 | 知识库问答 | 钉钉私聊发：**员工每年几天年假？** | 回复带 `[1]` 引用 + 📎 来源 → 说明 RAG 检索 |
| 2 | 工具调用 | 钉钉私聊发：**员工 001 是哪个部门的？** | 展示模型自主调了员工接口（数据来自 mock 内部 API） |
| 3 | 多轮对话 | 先发：**张伟是哪个部门的？** 再发：**他上周来上班几天？** | 说明按用户隔离的会话上下文 + 指代理解 |
| 4 | 拒答 | 钉钉私聊发：**我们公司 CEO 的家庭住址是？** | 展示"文档里没找到"，强调不编造 |
| 5 | Web 后台 | 浏览器展示「文档管理」「对话日志」 | 日志里能看到刚才钉钉的每一轮问答 |
| 6 | 实时生效 | 后台上传一份新文档 → 立刻回钉钉提问新内容 | 展示上传即建索引、增量生效 |

## 兜底方案

- 钉钉连不上 / 网络受限 → 用浏览器「**备用聊天**」演示同能力（不依赖钉钉）
- LLM Key 失效 → 故意把 `.env` 的 Key 改错后提问，展示 IM 友好报错（正好对应验收 7.5）
- 面试官想测群聊 → 群里添加小苏后 **@小苏** 提问即可
