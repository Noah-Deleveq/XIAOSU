# 面试演示脚本（10 分钟版）

## 准备（提前 5 分钟）

1. 本地启动：双击 `scripts/start_web.bat` 或执行 `sh scripts/start_web.sh`，打开 http://localhost:5173；钉钉 / 飞书由本地实例直连。
2. 本地一起启动 Web 后台和 IM，钉钉 / 飞书由本地实例直连。
3. 打开钉钉或飞书，准备好「小苏」的私聊窗口；面试官可以提前加入测试群。

## 演示流程（按顺序）

| # | 环节 | 操作 | 讲解要点 |
|---|---|---|---|
| 1 | 知识库问答 | IM 私聊发：**员工每年几天年假？** | 回复带 `[1]` 引用 + 📎 来源 → 说明 RAG 检索 |
| 2 | 工具调用 | IM 私聊发：**员工 001 是哪个部门的？** | 展示模型自主调了员工接口（数据来自 mock 内部 API） |
| 3 | 多轮对话 | 先发：**张伟是哪个部门的？** 再发：**他上周来上班几天？** | 说明按用户隔离的会话上下文 + 指代理解 |
| 4 | 拒答 | IM 私聊发：**我们公司 CEO 的家庭住址是？** | 展示"文档里没找到"，强调不编造 |
| 5 | Web 后台 | 打开 http://localhost:5173，展示「文档管理」「对话日志」 | 日志里能看到刚才 IM 的每一轮问答 |
| 6 | 实时生效 | 后台上传一份新文档 → 立刻回 IM 提问新内容 | 展示上传即建索引、增量生效 |

## 兜底方案

- IM 连不上 / 网络受限 → 用本地 Web 后台的「备用聊天」演示同能力
- LLM Key 失效 → 在 Web 后台「设置」页把供应商切到未配置的一家，展示友好降级
- 面试官想测群聊 → 群里添加小苏后 **@小苏** 提问即可
